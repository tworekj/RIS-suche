# Informationsseite für Datenschutz und Cybersecurity

Diplomarbeit an der HTL Wien West (Informatik für Berufstätige), Schuljahr 2026/27.

Eine KI-gestützte semantische Suche für die Gesetze zu Datenschutz und Cybersecurity
(DSGVO, DSG, NISG, TKG 2021, ausgewählte StGB-Paragraphen). Benutzer*innen beschreiben
ihr Problem in eigenen Worten und bekommen die passenden Gesetzesstellen im
Originalwortlaut samt Quellenangabe und Link zum RIS.

Sprachmodelle verarbeiten nur die Suchanfrage. Es werden keine Antworten erzeugt.
